This application is meant to help schedule tee times at a private golf course and is invite only.

Author: Alex Coffin

Chrome extension
  chrome://extensions -> enable Developer mode -> "Load unpacked" -> select the MediTee folder.

Python helper (teetime.py)
  Install uv (https://docs.astral.sh/uv/), then:
    export MEDITERRA_USER=your_username MEDITERRA_PASS=your_password
    uv run teetime.py
